## 设计说明

- **高明色调**：米纸底 `#F7F4EC` + 炭墨字 `#262321`，不用蓝；点缀色为赤陶 `#B4543A`、
  鼠尾草绿 `#6E7F5C`、琥珀金 `#C08A2E`、石墨 `#40403F`、雾紫 `#8C7B96`（对应五期）。
- **制图纸隐喻**：背景铺 32px 淡格线，区块编号用描边空心数字，卡片硬阴影错位，
  呼应原书「建筑师户外速写本」的形制。
- **图片来源**：全部取自 Wikimedia Commons 开放授权（CC BY / CC BY-SA / CC0 / 公有领域），
  逐张署名，可查证。原书 600 幅手绘插图属作者版权，仅作条目对照，不复制。
