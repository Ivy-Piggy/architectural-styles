C 爱琴海与古希腊【迈锡尼 3 条 + 古希腊 8 条已录入；米诺斯待补】
  总特征：卫城（acropolis）与防御工事 · 大型门道 · 陵墓（圆顶墓 / 蜂巢式）
  材料：巨石式（Cyclopean）石灰岩 —— 大石灰石砌墙、小石灰石填缝
  结构：叠涩穹窿顶；石过梁 + 卸载角（relieving triangle）分散梁上方重量
  雕塑：门楣上方三角楣内的浮雕 —— 狮子门双狮
  已录入 3 条（第 17–19 条，2026-09-29 增补）：
   17 迈锡尼卫城，阿尔戈利斯，希腊，前1350–1200年
      特色：巨石式城墙（Cyclopean）；位于爱琴海与希腊大陆之间的要冲；「巨石式」一词由希腊人提出，他们认为只有独眼巨人库克洛普斯才搬得动这些巨石
   18 狮子门，迈锡尼，希腊，前1250年
      特色：卫城主入口；两片巨石立柱 + 巨大石过梁，梁上三角楣内嵌双狮浮雕（该时期为数不多的雕塑）；门框内据推测曾装约 3 米宽的大门
   19 阿特柔斯宝库（阿伽门农墓），迈锡尼，希腊，前1250年
      特色：叠涩穹窿顶 = 蜂巢式陵墓；结构简单、体量巨大；石过梁上方三角开口＝卸载角，把重量分散到两侧
  已录入 8 条（第 20–27 条，2026-09-29 增补 · C–2 古希腊 · 神庙与公共建筑，前 900–前 100）：
   20 帕特农神庙，雅典（卫城最高处），希腊，前447–432年
      特色：列柱围廊式 + 梁柱结构；四侧列柱环绕，各方向视觉效果一致；两端列柱门廊 + 三角形山花（三角形屋檐结构的一部分）；内殿多柱回廊内有爱奥尼亚式浅浮雕檐壁；外缘多立克柱
      建筑师：伊克提诺斯 + 卡利克拉特（笔记原写「卡拉克拉特」，译名待核）
   21 伊瑞克提翁神庙，雅典（卫城北侧），希腊，前406年
      特色：把多个圣所结合成一个整体；六座女像柱充当南廊支撑柱；兼具爱奥尼亚式石柱与女像柱（建筑师「可能是穆内西克莱斯」，待核）
   22 赫菲斯托斯神庙，雅典，希腊，前450–415年
      特色：多立克式围廊建筑；一圈廊柱环绕内殿；有前殿与后殿，内殿与后殿不相通；内殿前端六根立柱（笔记「一个前殿和两个后殿」待核）
   23 雅典娜胜利神庙，雅典，希腊，约前420年
      特色：规模小；正背面均有列柱 + 正殿 / 后殿，属列柱围廊式；爱奥尼亚柱式；整块潘泰列克大理石整体雕刻（非圆形石块垒砌）；门廊浮雕出自帕特农雕刻者（建造者卡里克拉特；年代待核，通行约前426–421年）
   24 奥林匹亚宙斯神庙，雅典，希腊，前2世纪–公元2世纪
      特色：现存 15 根科林斯式立柱；流传希腊人视续建为过于自负；后由罗马人主持续建（「自负」之说与年代口径待核）
   25 李西克拉特音乐纪念碑，雅典，希腊，约前335年
      特色：立于高大的方形底座上；首次在建筑外部使用科林斯柱式
   26 风之塔，雅典，希腊，约前1世纪
      特色：潘泰列克大理石；测时功能为本体存在的重要原因；塔身八面指向八个方位，每面檐壁下装日冕、以阴影报时；塔顶原有青铜风向标（年代口径待核）
   27 西弗诺斯宝库檐壁，德尔斐，希腊，约前525年
      特色：同时期最具影响力的雕刻檐壁之一；以动物与奥林匹斯诸神之战及神话场景装饰；宝库几乎完全封闭，正面带山墙门廊、两端壁柱、中间两根女像柱（具体场景待核）
  总特征（C–2）：地位——迈锡尼文明衰落后，神庙成为建筑的中坚力量；形制——列柱围廊式（四侧列柱环绕、各向同观）+ 由有柱的门廊 / 前殿 / 内殿 / 后殿组成；理念——重视比例，以比例求平衡与对称；公共建筑——露天广场（agora）、角力学校、剧场（阶梯式山坡、层列式排座）、跑马场
  待补：米诺斯王宫（克诺索斯）· 剧场与竞技场原型

D 古罗马【伊特鲁里亚前身 3 条 + 罗马本体 7 条已录入；印度等古代东方待补】
  总特征：高台基、深前廊、后部封闭的神庙；土丘墓与岩凿墓室；陶制顶饰
  材料：石头地基 + 彩绘木头、泥砖、陶土（terracotta）
  柱式：托斯卡纳式（Tuscan）—— 外形类似加了基座的多立克柱；可查维特鲁威《建筑十书》
  已录入 3 条（第 28–30 条，2026-09-29 增补）：
   28 波托纳乔神庙，维爱，意大利，约前510年
      特色：受希腊建筑影响，伊特鲁里亚在公元前 600 年前后开始修建神庙；地基是石头做的，其余部分为彩绘木头、泥砖和陶土；此时诞生托斯卡纳式立柱；《建筑十书》可查
   29 班迪塔奇亚墓葬群，切尔韦泰里，意大利，前9–前3世纪
      特色：这里原是伊特鲁里亚古城，有三万人规模，故此有几千座墓葬；土丘墓（tumulus）成片，墓室凿于岩层，以墓道街巷相连
   30 伊特鲁里亚神庙的陶制顶饰，（维爱 / 切尔韦泰里等），约前6–前5世纪
      特色：屋顶和屋脊使用比真人还大的陶制人物形象作为山花顶饰（如山花上的阿波罗与拉托娜）；檐口的直立装饰物遮掩顶瓦边缘，酒神的女祭司为常见形象
  D–2 罗马本体（第 31–37 条，2026-09-30 增补）· 拱券、混凝土与帝国公共建筑
   总特征：罗马混凝土（opus caementicium）+ 券拱技术 → 换来大跨度室内空间；结构语汇 = 拱券 / 筒拱 / 十字拱 / 穹顶 + 券柱式（拱与柱式叠合）立面；建筑类型 = 神庙 / 巴西利卡（公共大厅）/ 剧场与斗兽场 / 公共浴场 / 凯旋门与纪念柱 / 水道桥；城市与居住 = 罗马广场（forum）为核心、多层公寓（insula）与宅邸（domus）；影响 = 把「拱券 + 混凝土」做成可复制的工程体系，后世文艺复兴再度复活
   31 万神殿，罗马，意大利，约118–126年
      特色：混凝土穹顶，直径与高度同约 43.3 米；正中顶部圆窗（oculus）采光，是室内唯一自然光源；穹顶自下而上逐渐减薄、骨料由重到轻（凝灰岩→浮石）；墙面设壁龛与暗柱；立面为希腊式柱廊门廊＝「希腊的立面 + 罗马的内部」（阿格里帕初建、哈德良时期重建，铭文与年代待核）
   32 罗马斗兽场（科洛塞姆），罗马，意大利，72–80年
      特色：四层立面 —— 下三层为多立克 / 爱奥尼亚 / 科林斯券柱式拱廊，顶层为实墙；结构用混凝土、外墙贴石灰华（洞石）；可容纳约五万观众；设地下服务层（vomitoria 快速疏散通道）（年代与容量口径待核）
   33 提图斯凯旋门，罗马，意大利，约81年
      特色：单拱券凯旋门范式；两侧混合柱式附壁柱；拱腹内浮雕表现提图斯凯旋 —— 一侧是耶路撒冷战利品（含七枝烛台），一侧是凯旋行列（年代待核，亦有 81–82 年之说）
   34 图拉真纪念柱，罗马，意大利，113年
      特色：高约 30 米（合 100 罗马尺）大理石柱；柱身螺旋浮雕带展开约 190 米，记录达契亚战争；柱内有螺旋楼梯；原与图拉真图书馆两座半圆厅合抱成院（含基座总高约 38 米；浮雕带 190–200 米之说待核）
   35 马克森提乌斯与君士坦丁巴西利卡，罗马，意大利，308–312年
      特色：巴西利卡（basilica，公共大厅）范式的晚期巨构；中殿由三座十字拱（高约 35 米）覆盖，靠混凝土筒拱与厚墙抵住侧推力；侧廊与中殿分层（现存仅北侧三座筒拱与一座十字拱；「长方形会堂」为另一常见译名）
   36 卡拉卡拉浴场，罗马，意大利，212–216年
      特色：大型公共浴场，帝国社交场所；主体沿中轴对称排布冷水厅 / 温水厅 / 热水厅，覆以拱顶与穹顶；另有运动场、图书馆与花园（启用年有 216–217 年之说，待核）
   37 加尔桥（水道桥），尼姆附近，法国，约50年
      特色：三层连拱水道桥，高约 49 米；最上层为输水槽；石材干砌、不用砂浆；拱跨度自下而上递减以减重（年代区间 40–60 年、长约 275 米，待核）
  待补：罗马住宅（domus / insula）与庞贝城市 · 罗马剧场原型 · 罗马广场（forum）
