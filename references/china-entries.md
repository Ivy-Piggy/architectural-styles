## 一、原始笔记（保持原文，未改一字）

```
古代中国 主要特征：大木结构，榫卯结构、曲线屋脊和翼角，屋脊兽，寺庙和宫门口的狮子像，琉璃瓦，鲜艳的色彩系统
1103年 李诫《营造法式》
拙政园，苏州，江苏，中国，16世纪，特征：以水为中心分为三个部分，信步园中，厅堂亭榭，游廊石桥，山水风物，如中花园的"梧竹幽居"四个圆洞门构成了重叠交错空间
翼角，中式园林典型特征，排水防火，惊走鸟类。
天坛，北京，中国，1420年，特征：三座主体建筑，三层汉白玉台基，天圆地方概念，
滕王阁，南昌，江西，中国，653年，重建29次，江南三大名楼
佛宫寺释迦塔，应县，山西，中国，1056年，特征：应县木塔，平面八边形，塔内九层，外观五层，出名的斗拱，共54种斗拱
故宫，北京，中国，1405-1420年，特征：皇家建筑，东西南北四座大门，午门（主入口），神武门（主出口），东华门，西华门，大门位于10米高夯土城墙内，由宽52米、深6米的护城河环绕
颐和园，北京，中国，1751年，特征：原计划九层，但最终建筑成了八面三层的佛香阁，供奉观音
布达拉宫，拉萨，西藏，中国，1645年，特征：政教合一，依山而建，夯土砖石砌成
洪崖洞，重庆中国，14世纪，洪崖洞一带主要是吊脚楼，延长江和嘉陵江而建设，建筑11层，
四合院，特征：二进院落，前院小，后院大，两侧住房，
悬空寺，大同，山西，中国，491年，特征：恒山悬崖之上，了然和尚一人建造，位置独特免受洪水、山雨、大雪侵扰，寺庙完全插入山崖石壁，靠横梁和立木支撑，主殿六座，小殿34间，栈道链接
嵩岳寺塔，登封，河南，中国，520-525年，原为北纬宣武帝、孝明帝离宫，6世纪晚期改为佛寺，特征：现存最老砖塔，平面呈现十二边形，外观15层，内部十层，塔身印度佛塔影响，自下而上逐渐收拢，柔和的抛物线轮廓。
```

**录入时对原文的三处技术性更正**（内容未变，只修字）：

### 总特征（大木构体系）与八个构件

| 维度 | 内容 |
|---|---|
| 结构 | 大木结构（抬梁／穿斗），墙不承重 —— 「墙倒屋不塌」 |
| 节点 | 榫卯：不用钉，靠凹凸咬合，节点可小幅转动，抗震 |
| 屋面 | 曲线屋脊与翼角起翘；排水、遮阳，也划定天际线 |
| 材料 | 琉璃瓦（黄为帝、绿为官）、青砖、木材 |
| 装饰 | 屋脊兽、门口石狮、彩画 |
| 色彩 | 鲜艳的色彩系统：朱红柱身、青绿彩画、金饰 |
| 文本 | 1103 年 李诫《营造法式》 |

**八个构件（页内自绘 SVG 线图）**：抬梁式大木作 · 榫卯 · 斗拱 · 翼角 · 屋脊兽 · 琉璃瓦 · 石狮 · 圆洞门
